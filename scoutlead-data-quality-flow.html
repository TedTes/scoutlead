RULES

Reliability invariants

These conditions must remain true across every niche and city.

  1. Raw evidence is immutable. If a payload is intentionally cleaned, its content hash must be updated in the same transaction.
  2. A claim belongs to one observation and business. Cross-business links are integrity failures.
  3. A staged fact is allowed. It represents the current resolved value before approval; it must not enter audience results.
  4. Validation results are decisions, not processors. The worker must explicitly run validation and update the fact state.
  5. Uncertain evidence stays staged. Failed evidence becomes rejected; only passed evidence becomes published.
  6. Audience retries follow real dependencies. A run should retry after required signal jobs finish, then terminate as ready or partial.
  7. No niche-specific repair. The same orchestration must work for garage doors, painters, HVAC, and future database-driven niches.
